# GRAVITY SYNC／重力節拍

科技重力場風格的人形動作音樂節奏遊戲。人形隨音樂接近判定區，玩家在拍點做相同姿勢得分。

## 下載完整交接包

**[下載交接包 ZIP（約 15.1 MB）](./gravity-sync-handoff-v2.zip?raw=true)**

內含完整原始碼、本機 MediaPipe 模型與 WASM、啟動器、技術架構、接手清單、測試、截圖及錄影片例。程式不需要 API key 或雲端服務，模型已隨包附上。

快照版本：V2，2026-10-21 整理交接；既有互動與影片驗證紀錄日期為 2026-10-08。

## 啟動

1. 下載 ZIP 並完整解壓。
2. 先閱讀 `00_交接必讀.md`。
3. 進入 `重力節拍互動遊戲`，Mac 可雙擊 `啟動重力節拍.command`。需要 Python 3。
4. 或在遊戲資料夾執行 `python3 server.py`（Windows 可用 `py -3 server.py`），開啟 <http://127.0.0.1:8876/>。

不要直接雙擊 HTML，模型須經本機 HTTP 伺服器載入。Node.js 僅用於測試；不需要 npm install。

## 目前功能

- 五種上半身姿態、鏡頭辨識、姿勢幾何精準度及具體修正提示。
- 八首原創即時合成器樂、兩種難度，包含 Techno、DnB、Hip-hop、Funk、Synthwave。
- 三種判定舞台、三種辨識預覽；紫／藍／橙／綠明確區分遠中近與命中窗。
- 整場／手動錄影、拍照、回放、最佳連擊選段及帶音樂片段匯出。

影像在瀏覽器本機處理，不錄麥克風。照片與影片刷新後會消失，請先下載。內建音樂是合成器樂，尚無外部歌曲上傳、自動 BPM 或自訂譜面功能。

## 驗證狀態

交接包解壓後已通過 SHA-256 完整性檢查與 11 項引擎測試。既有相機整合證據使用官方測試照片產生的合成影像串流；**真人攝影機完整遊玩、現場投影延遲及各瀏覽器編碼相容性仍需實測**。詳細內容見包內 `02_驗收與限制.md`。

以 Node.js 18 以上在遊戲目錄執行 `node --test tests/engine.test.js`。在交接包根目錄執行 `python3 verify_package.py` 可檢查包內檔案。
